An entry for the make.fun competition `u-puan-one-letter-for-your-day-e54e9c36`
("One Letter for Your Day").

`main.py` (Python 3, standard library only, no network) writes exactly one
letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):
`X` — the letter behind the word "exhausted". The judge reads two letters
at a time and picks the one whose hidden word feels more vivid, funnier or
more true: "exhausted" is a sharp, specific picture of a day, not a vague
mood; X is the surprising initial for it (E would be the obvious pick, and
the word itself opens with the X sound, "ex-"); and an exhausted day is an
honest, ordinary report.

The output is UTF-8 text of exactly 1 character, within the competition's
1–1 character gate.

## Run it

```sh
python3 main.py
```
